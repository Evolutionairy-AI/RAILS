# rails-ref

Reference implementation and adversarial harness for the **RAILS** verification-native clearing protocol — the admissibility-graded Verification Mesh with the soundness property `Emit(S) ⟹ cls(B) ⪰ φ_O`.

This package lets a third party (a) run the clearing core, (b) reproduce the paper's empirical figures with one command, and (c) check conformance to the specification.

See the spec at `../docs/superpowers/specs/2026-06-02-rails-reference-harness-design.md`. Full usage and reproducibility instructions land in this README at Task 22.
